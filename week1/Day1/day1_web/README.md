# Day 01 웹 실습실

`index.html`을 더블 클릭하거나 브라우저에서 열면 실행됩니다. 서버, Python, Node.js, 패키지 설치, 인터넷 연결이 필요하지 않습니다.

## 구성

- `index.html`: 실습 선택, 입력 폼, 결과, Python 코드 표시
- `styles.css`: 데스크톱과 모바일 화면 스타일
- `app.js`: 덧셈, 합격 판정, 짝수 추출, 구구단, 숫자 맞추기 로직

## 사용

실습을 선택하고 값을 입력한 뒤 **실행하기**를 누릅니다. 구구단은 입력 없이 실행합니다. 숫자 맞추기는 **새 게임 시작**으로 다시 시작합니다. 새로고침하거나 다른 실습을 선택한 뒤 돌아오면 게임이 초기화됩니다.

Python 파일의 동작을 JavaScript로 옮긴 웹 버전입니다. 화면에 표시하는 Python 코드는 참고용이며 수정하거나 실행하는 편집기는 아닙니다. 동작을 바꾸려면 `app.js`를 수정하고 새로고침하세요. Python 모듈을 수정한 경우 웹 버전도 별도로 수정해야 합니다.

모든 입력은 정수로 검증합니다. JavaScript에서 정확히 표현할 수 있는 정수 범위(±9,007,199,254,740,991)를 사용하며, 덧셈 결과가 범위를 넘으면 안내합니다. 숫자 맞추기는 1~100만 허용합니다. 점수와 리스트 실습은 원본처럼 별도 범위 제한이 없습니다.

모든 데이터는 페이지가 열려 있는 동안 브라우저 메모리에만 유지됩니다. 외부 요청과 백엔드 기술을 사용하지 않습니다.
